登入 Microsoft 帳號

透過 Microsoft OAuth 登入或重新登入目前帳號。

登入完成後，本頁面會自動確認授權結果，通常不需要複製 callback URL。
自動完成失敗？使用手動備援
此備援不代表 Microsoft 登入失敗；只有登入已完成，但自動 handoff 無法將結果交回 Sidecar 時才使用。
請貼上瀏覽器最終完整 callback URL；若只有授權碼，請輸入 code=...&state=...。授權碼有時效且只能使用一次，資料只會透過受限 JSON POST 提交，不會放入 URL query。
若使用者取消、授權逾時、state 不符或權杖交換失敗，請重新產生授權連結，不要重複提交舊資料。
Sidecar 會開啟或附著可控的 Chrome 系瀏覽器，並在網址跳到 wrongplace 前自動擷取瞬時 PKCE callback。登入資料會先隔離驗證，不會在驗證前取代目前使用中的 Microsoft 帳號。
